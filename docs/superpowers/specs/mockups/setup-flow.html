Situações de exceção previstas

  • Senha do WiFi errada: o gadget volta para o passo 1 mostrando "Senha incorreta" na tela.
  • mDNS não acha o gadget (WSL2, rede corporativa): /gadget pair 192.168.0.42 usando o IP que aparece no passo 3.
  • Vários gadgets: /gadget pair lista todos, e o código escolhe qual. Dá para parear vários de uma vez.
  • Resetar tudo: segurar o botão por 10s volta ao passo 1 (se o hardware tiver botão acessível; senão, pela página do gadget).
  • Trocou de rede ou o roteador mudou o IP: o bridge redescobre pelo ID do gadget via mDNS, sem precisar parear de novo.
